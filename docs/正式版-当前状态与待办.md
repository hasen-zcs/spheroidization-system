# 正式版 · 当前状态与待办（2026-10-31 基线）

## 一、这一版做了什么

以老板提供的两份包为起点（后端包 = 新后端 + 旧前端，前端包 = 新前端 + 旧后端），
组装出**可运行、可部署、前后端对得上**的第一版正式基线。

| 项 | 状态 |
|---|---|
| 后端 `app/` 取新包（账号权限 / 温度拆表 / 标准切换 / 启动自检） | ✅ |
| 前端 `frontend/` 取新包（登录 / 用户管理 / 权限 / 标准切换） | ✅ |
| 5 处前后端契约不一致 | ✅ 已修（详见 README「契约兼容说明」） |
| 人工补录带温度被 422 | ✅ 已支持（写入温度表，gun_no=0） |
| 停用账号仍可登录 | ✅ 已拦（登录 401） |
| `abnormal_type` 上限 1~4 | ✅ 放宽到 1~6（对齐 vpmin） |
| 老库直接换代码不建新表 | ✅ 启动自检拦截 + `scripts/migrate_db.py` |
| 自动化验证 | ✅ pytest 102 passed；前端 build 通过；浏览器 E2E 32 项全过（dev + 生产包各一轮） |
| 前后端全链路 | ✅ 17 个后端接口 × 游客/普通用户/管理员逐条对齐（见下节） |
| 视频流链路 | ✅ 后端新增反向代理，单进程部署不再黑框 |
| 前端托管 | ✅ 后端直接托管 dist，前后端同源，无需 nginx |

迁移脚本实测：9 月结构 + 2 条带温度记录 → 迁移后表齐全、行数一致、温度落到
`TemperatureRecord`（gun_no=0）、幂等复跑跳过。

## 二、还没做的（按优先级）

### P0 · 检测侧对接（不做则新检测数据进不来）

1. **上游检测程序改温度上报**：球化记录里不再带 `spheroidization_temperature`，
   改为调 `POST /api/temperature`（带 `gun_no`，`spheroidization_record_id` 可空、后挂）。
2. **`abnormal_type` 口径**：后端已收 1~6，需检测侧确认映射
   （3 超标准 / 4 低于标准 / 5 分段多次 / 6 未判定）；1 进站未球化、2 进线中断尚未实现。
3. **`plc_button_time`（按钮时刻）未落库**：R1~R8 方案里有这一列，本次后端没有。
   要做需加列 + 实体 + 请求模型 + 前端展示 + 迁移。
4. **`FlashSegment`（分段明细）未实现**：vpmin 已产出分段（gap_before 等），
   正式版还没有表与接口。要做需新表 + POST 子结构 + 详情页展示。

### P1 · 现场部署

5. 后端静态托管前端 `dist/`（或 nginx），视频流 `/api/video_feed*` 反代到 5080。
6. Windows 现场服务化：开机自启、崩溃重启、日志轮转（当前只有 `uvicorn` 手动启动）。
7. 单 worker 约束写进部署脚本（多 worker = 随机 401）。
8. 备份/恢复流程：`data/spheroidization.db` + `data/active_standard.json` 必须同批备份。

### P2 · 功能补齐

9. 首页/报表：按班次、按标准、按异常类型的统计（现在只有 4 个总数）。
10. 数据导出（Excel/CSV）与打印。
11. 温度匹配策略（枪 4 / 按钮前后 600s / 占用制）——目前后端只存不匹配，
    匹配规则要么放检测侧，要么放查询侧，需要定口径。
12. 图片接口的游客可见性、监控页游客范围复核。
13. 用户密码策略（长度、复杂度、首次登录改密）。

## 四、这一版的已知边界

- 会话在内存：重启后所有人重新登录；必须单进程。
- 温度 `gun_no=0` = 历史迁移或人工补录，不是真实枪号。
- 老库迁移只覆盖 v1.2（2026-09）结构；更早的结构需先升到 v1.2。
- 前端 E2E 用迁移样本库（2 条记录、2 套标准）验证，未接真实检测流。


## 五、本轮全链路打通清单（2026-10-31 23:xx）

| 链路 | 修复前 | 现在 |
|---|---|---|
| 登录 → 登录态 | 前端读 `data.user` 拿不到 | 后端返回嵌套 user + permission_keys |
| 用户列表/详情 | `permission_keys` 缺失，页面抛异常 | 双字段兼容，权限勾选可预填 |

| 标记处理 | 裸 POST 无 body → 422 | 后端允许空体 |
| 人工补录温度 | extra=forbid → 422 | 可随记录带温度（gun_no=0） |
| 异常结果展示 | null 显示成"正常" | 三态：异常/正常/未判定 |
| 布尔字段 | 后端返 0/1，前端声明 boolean | 统一返回 true/false |
| 视频流 | 仅 Vite 开发代理，上线 404 | 后端反代 + `VIDEO_FEED_BASE` |
| 前端托管 | 必须另配 nginx | 后端托管 dist + SPA 兜底 |
| 过期登录态 | 公开页不报错，界面挂着假登录 | 启动时 /me 校验，401 自动回登录页 |
| 权限拦截 | 只在接口层 | 路由守卫 /403 + 接口 403 toast |
